## Bundled third-party code

**None.** The extension ships no vendored libraries, no frameworks, and no minified bundles.
There is no `package.json`, no `node_modules`, and no build step — the source that is read is
the source that runs. The only runtime dependencies are the browser's own APIs (`chrome.*`,
`Intl`, `fetch`) and, for the test tools, Node's standard library (`node:fs`, `node:path`,
`node:zlib`, `node:url`, `node:module`).

Everything in `icons/` is generated by `tools/make-icons.js` rather than committed as an opaque
binary, so there is no third-party artwork either.

## Data providers

The extension makes network requests to exactly two hosts, both public price endpoints. Both
free tiers ask for attribution, which the extension gives in the popup, in Options, and on the
welcome page.

### CoinGecko — `api.coingecko.com`

Cryptocurrency prices. Used through the free public API, or through the Demo tier if the user
supplies their own API key in Options.

- Attribution: **"Prices by CoinGecko"**, shown in the extension UI with a link to
  <https://www.coingecko.com>.
- Terms: <https://www.coingecko.com/en/terms> — API terms and tier limits at
  <https://www.coingecko.com/en/api/pricing>.
- The free and Demo tiers carry rate limits and restrictions on some commercial uses. This
  project is non-commercial and charges nothing. **Anyone forking it into something that charges
  money must re-read CoinGecko's terms and, if required, obtain a paid plan** — the MIT licence
  on this code does not grant you anything with respect to CoinGecko's service.
- API keys are the user's own. None is bundled, and a supplied key is stored only in
  `chrome.storage.local` and never given to the script running inside the casino's page.

### exchangerate-api — `open.er-api.com`

Fiat exchange rates, through the Open Access endpoint, which requires no key.

- Attribution: a link to <https://www.exchangerate-api.com>, shown in the extension UI, as the
  Open Access tier requires.
- Terms: <https://www.exchangerate-api.com/terms>.

Neither request carries personal data, an account identifier, or anything about the user's play.
See [PRIVACY.md](PRIVACY.md) for exactly what leaves the machine.

## Third-party services the extension reads but does not depend on

Stake and Duel are read in the user's own browser, in the user's own session. Nothing is
redistributed from them: no markup, no logo, no brand asset, no captured response is committed
to this repository, and the test fixtures are synthetic. Their names appear here only to
describe which sites the code works with. See [DISCLAIMER.md](DISCLAIMER.md) for the affiliation
and trademark position.
