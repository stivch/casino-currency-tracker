Use the casino's own price table Both sites publish a currency table, most major fiats included, to price what they show you — and converting with it means converting with the same number the balance on screen was drawn with. Pinned amount

The readout follows each site's own balance chip on its own, so there is normally nothing to do here. Both sites tag that chip with an id they keep stable across releases, while the markup underneath it is regenerated whenever the balance changes — which is why following the chip survives what a pin on the digits does not. Pin something yourself only to follow a different number; it is remembered per site, and if it ever stops resolving the readout falls back to the chip rather than asking to be pinned again.

Session & limits

Sessions are filed automatically once they go quiet, and whenever you reset one. Each is recorded with the rate that applied when it closed, so an old session keeps the figure it actually had rather than being restated at today's rate. The coin's dollar price and the exchange-rate table are stored alongside it, so the same session can be read in a currency you pick later — still at that evening's rates.

End a session after Minutes without a bet before the session is considered finished.

Limits

Each one flags in the overlay and, if you want, as a desktop notice. Nothing is blocked and no bet is stopped — these report, and the reading is yours.

Wager limit Flags in the overlay once this session's turnover passes it. Blank = off.
Loss limit Flags once the session is down by this much. Blank = off.
Win limit Flags once the session is up by this much — a take-profit marker. All three are in the currency you convert to, compared at the current rate. They can also be set straight from the toolbar popup.
Time limit (minutes) Flags once the session has been running this long. Counted from its first bet, not from opening the tab, and it needs no rate — so it applies to every coin. Blank = off.

What it costs

Every game takes a fixed cut of what you stake, and rakeback hands a fraction of that cut back. Neither figure is shown anywhere on the casino — Stake displays a rakeback balance, not what it is a fraction of. Rakeback is a discount on losing, not a way of winning: because it is a percentage of the house edge, it returns the same share of your expected loss whatever you play, so it cannot make one game better than another. A higher-edge game pays more rakeback because it is taking more.

House edge % The cut the games you play take. Stake's own originals — dice, limbo, mines and the rest — are 99% RTP, so 1%. Slots are usually higher and vary per title; a slot's RTP is on its own info panel. One figure stands in for every game for now.
Rakeback % of the edge Stake's help centre says 3.5% of the house edge; some third-party calculators say 5%. Only used until the extension has watched enough rakeback actually arrive, at which point it reports the rate you are really being paid instead.

By year

Every session totalled at the rate it closed with, grouped by calendar year by default. Sessions recorded before a rate was ever fetched have no converted figure and are counted separately rather than silently left out.

Tax year starts in January is the calendar year, which is Israel's tax year. The UK's opens in April and Australia's in July. This changes only how sessions are grouped below — no figure is recalculated.

Sites

The extension runs only on the domains listed here and nowhere else. That is a limit on purpose: what it knows about a casino is a set of assumptions about that one site's bet ledger, and pointing them at a site they were not written for does not fail — it produces confident wrong numbers. Support for a new casino is a new version, not a setting.

Also run on Extra domains these casinos answer on, switched off until you pick one. Chrome asks to allow access; you can withdraw it at any time from Chrome's own extension settings.

Backup & data

Everything lives on this machine, so uninstalling the extension deletes the history with it. The backup is one JSON file — settings and recorded sessions, no API key. Importing merges: existing sessions are kept and duplicates are skipped, so restoring an old file never deletes a newer session.
